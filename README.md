# Дашборд регистраций на мероприятие

Одностраничный дашборд для организатора: за минуту видно, сколько человек зарегистрировалось, сколько оплатило и откуда они пришли.

## Что показывает

- **Три крупные цифры:** всего регистраций, оплатили, не оплатили (с долей от всех).
- **Таблица по каналам** (Telegram, Instagram, Email-рассылка, Сайт, Партнёры).
- **Таблица по городам.**
- **Таблица по типам билета** (Стандарт, VIP, Онлайн).

В каждой таблице: Всего / Оплатили / Не оплатили / % оплаты и строка «Итого». Строки отсортированы по числу регистраций.

## Как открыть

Откройте `index.html` двойным кликом в любом браузере. Интернет и установка программ не нужны: страница не подключает внешних библиотек, шрифтов и скриптов.

## Как обновить данные

Данные из `registrations.csv` вшиты в страницу без имён (только город, дата, канал, билет, оплата). Чтобы посмотреть свежие данные, нажмите **«Загрузить другой CSV»** и выберите файл. Обработка идёт прямо в браузере, файл никуда не отправляется.

Формат CSV (кодировка UTF-8, первая строка — заголовки):

```csv
city,registered,source,ticket,paid
Астана,2026-10-30,Telegram,VIP,да
```

| Колонка      | Описание                                              |
|--------------|-------------------------------------------------------|
| `city`       | Город                                                 |
| `registered` | Дата регистрации                                      |
| `source`     | Канал, откуда пришёл участник                         |
| `ticket`     | Тип билета                                            |
| `paid`       | `да` — оплатил; любое другое значение — не оплатил    |
